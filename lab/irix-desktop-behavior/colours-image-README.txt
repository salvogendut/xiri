
Desktop preferences and Solid colours:
Use Toolchest Desktop -> Customize -> Background, Color Schemes or Windows.
Each user keeps separate settings across logout/login and reboot.
If Windows asks to restart 4Dwm, choose Cancel, then log out/in to apply.

For a solid backdrop, select Solid and click the colour square under its
preview. Select a colour in Backgrounds: Color Browser, press OK, then Apply
in the Background panel. Log out/in to check the restored desktop colour.
A reopened chooser starts from the template blue in the current test; check
its preview before applying again. Comparison with original IRIX remains open.
The original picker uses its ordinary X11 controls; its GL mode crashes the
bundled software renderer. SGI colour names are supplied through a private
per-session Xcms database derived from the already imported IRIX rgb.txt.
The display's numeric-colour quantization remains; exact RGB fidelity is not
claimed. Other preference panels and saved application sessions need testing.

Xmahjongg starts only when launched from Freeware or winterm.
The image retains its initial backdrop; test colour profiles are not preseeded.
Back up ~/.Sgiresources and ~/.desktop-<hostname>/ together.
See docs/IRIX-SOFTWARE.md#desktop-preferences for settings and backup guidance.
