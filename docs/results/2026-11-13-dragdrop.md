# Running-application file drops

The native desktop runtime now includes a per-user SGI-to-XDND adapter and
an additive correction for gedit's application-icon Drop action. The kernel,
IRIS fork and imported application binaries are unchanged. This cycle uses
IRIX 6.5.22m applications on NetBSD/sgimips, R4400 Indy, native accelerated
Newport Xorg at 1280×1024.

## What changed

File Manager offers `_SGI_ICON` through Motif drag-and-drop. The imported GTK
clients require `text/uri-list`. `drop-bridge` translates local file records,
including spaces, doubled quotes, literal backslashes and multiple records.
It negotiates copy/open, checks the receiving client's reply, and never asks
the source to delete or move its files. It runs inside the authenticated
user's supervised desktop and is absent from the native ctwm session.

The old gedit filetype rule supplies `-f`, which this binary rejects even on
the original IRIX installation. Xiri adds a higher-priority rule using
positional document arguments and the original artwork. The updater compiles
both native and application rules before atomically replacing the database;
an invalid application rule leaves the existing table intact.

## Remaining limits

GIMP 1.2's Unix URI reader strips `file:` without decoding escapes. A running
window receives `colour sample.png` but attempts to open the encoded name;
use its application icon or File → Open for such names. This is consistent
with the [public GIMP 1.2.5 source](https://github.com/GNOME/gimp/blob/GIMP_1_2_5/app/gimpdnd.c#L1215).
Protocol completion means that the URI was transferred, not that every
application successfully opened its document.

Remote icons, non-file objects, payloads over 64 KiB, batches over 256 files,
and arbitrary document handlers remain outside this adapter's scope.
Registered Motif drop regions and other proxies are left untouched. The
helper restores its receiver properties on orderly termination; a forced
kill can leave a live application's proxy property stale until that client
or the X session restarts. Printing and other application-specific handlers
remain separate roadmap items.
