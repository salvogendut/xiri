## Disk and network checks

Each release started from its own framed-console O2 CHD. The guest wrote two
32 MiB files to its FFS root three times, swapping their contents each round,
syncing and checking both SHA-256 hashes. After a clean shutdown to the
graphical PROM, a new emulator process booted the same test overlay with the
source CD disconnected. The check read the clean-root message from the
graphical console and verified both files against the host's original hashes.

The cold guest used `mec0` to download a separate 32 MiB file over HTTP. It
then uploaded one of the files that had survived the cold boot over TCP. The
guest checked the download digest. The host checked the upload length and
digest. The qualification record includes the interface counter differences
and elapsed times observed with both release checks running concurrently.

## Enable Ethernet on the manual images

The November 23 O2 frame images start with carrier on `mec0` and DHCP
disabled. On either of those images, run this as root inside NetBSD to enable
IPv4 DHCP now and on subsequent boots. This file is the lab image's
per-service override.

```sh
printf '%s\n' dhcpcd=YES 'dhcpcd_flags="-q -4 mec0"' > /etc/rc.conf.d/dhcpcd
/etc/rc.d/dhcpcd start
```

With the bundled launchers, `ifconfig mec0` should show `192.168.0.2/24`,
and `route -n get default` should show gateway `192.168.0.1` on `mec0`.
The setting is saved to that launcher's writable overlay.
[Launchers](2026-11-23-o2-frame.md)

## Repeat the qualification

From the Xiri checkout, use a fresh output path for each run. The harness
checks the base disk and PROM hashes and uses loopback listeners for the host
HTTP and TCP endpoints. It removes the payload ISO, received files and
writable test disk on exit.

```sh
for version in 6.5.22 6.5.30; do
  IRIS_NO_IDLE=1 python3 lab/irix-o2/check-io.py \
    --bundle ".work/native/xiri-o2-frame-${version}-20261123" \
    --emulator .work/emulators/iris-ip30-jit-08e53ba7 \
    --output ".work/o2-io-${version}"
done
```

The IRIS `xiri` build at `08e53ba7` already contained upstream/main
`a05289ef` at the November 23 fetch. These runs exercise SCSI and MEC through
the emulated IP32. Physical O2 storage, Ethernet and cache/DMA coherency
remain to be qualified.
