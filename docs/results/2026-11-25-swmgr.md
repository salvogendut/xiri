# Installing and removing Freeware with SGI Software Manager

SGI Software Manager 4.1 installed xmahjongg 3.6.1 from the May 2004
Freeware CD 4 on both clean Mozilla Indys. After reboot, `xiritest`
double-clicked the game's Freeware icon and opened a 1006×614 window.
Removal through the same graphical installer restored each release's
original desktop artwork. [Try it on a clean Indy](../../lab/irix-installer/README.md#install-with-graphical-software-manager).

## What the installer changed

Each guest mounted the complete CD 4, containing 144 product inventories.
The helper opened the disc's `fw_common` and `fw_xmahjongg` distributions
in Software Manager and preselected only `fw_common.sw.index` and
`fw_xmahjongg.sw.xmahjongg`. The operator applied the selection with
**Start**. SGI's package hook registered the game in Icon Catalog and
compiled the filetype artwork. Setting the SGI preference `background:off`
kept Software Manager attached to the helper until the operator chose
**Exit, installations completed**. The helper could then verify SGI history
and publish the merged filetype table.

On both releases, closing Software Manager before applying removal left
the game installed. The helper reported this on the root console. The game
link, installation history and merged artwork still matched the installed
state. Applying removal deleted the executable, catalog link and three
game history rows. The three shared-index rows and **FreewareRelnotes**
remained. Each restored `desktop.otr` matched its own pre-install SHA-256.

The repeatable check also opens Mozilla before installation and after
removal. It sets a local homepage as `xiritest`, checks the preferences,
bookmarks, homepage and xdm session selector, and verifies the kernel,
module, boot wrapper, resolver service, account database and Xiri install
receipts. [R4400 saved homepage](2026-11-25-swmgr-6.5.22f-browser.png)
· [R5000 saved homepage](2026-11-25-swmgr-6.5.30f-browser.png)
· [Input hashes and guest observations](2026-11-25-swmgr.json)
· [Qualification command](../../lab/native-package/README.md#original-sgi-installers-and-freeware-cd-4).

In the first parallel run both emulators attached to host X display 101.
When the R5000 shut down, the R4400 lost its display during the final
login, after its removal and checksum checks. We repeated the R4400
qualification separately and verified independent display allocation
with two concurrent Indy PROMs. During that repeat the host interrupted
the runner while it waited for Mozilla. The guest found the saved homepage
title and halted cleanly. The final browser capture and logout check used
the same post-removal disk overlay on its next boot. The R5000 completed
the entire sequence in one run. [Test environment](../DEVELOPMENT.md).

Software Manager warned that it could not identify the CPU hardware and
architecture on both Indys. Both transactions completed. The [xosview and UnZip follow-up](2026-11-26-freeware-upgrade.md)
covers a second graphical program and a version-to-version upgrade.
