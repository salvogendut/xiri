## Reproduction

The reusable seed comes from the previous qualified CHD, not a diagnostic
guest. Its frozen raw disk is hash-verified before cloning. Preparation
verifies the inherited payload, installs the replacement kernel and unchanged
module, builds the native runtime, and checks graphical disk autoboot at
1280×1024. It then cleanly halts. The preparation run is
`.work/xdm-image/prepare/ordinary-1h76eoyu`.

```sh
python3 scripts/prepare-xiri-seed.py \
    .work/images/xiri-netbsd-desktop-20261105-fonts \
    --output-directory .work/xiri-image/seed-f8572195a17a
python3 scripts/prepare-xiri-xdm-image.py \
    --seed .work/xiri-image/seed-f8572195a17a \
    --kernel-build .work/netbsd-fpu-build \
    --baseline lab/type1-scaler/baseline.json --keep-accounts
python3 scripts/build-xiri-image.py \
    --seed-run .work/xdm-image/prepare/ordinary-1h76eoyu \
    --output-directory .work/images/xiri-netbsd-desktop-20261105-type1 \
    --baseline lab/type1-scaler/baseline.json \
    --kernel .work/netbsd-fpu-build/tftp/netbsd-XIRI_INDY \
    --iris-bin-dir .work/images/xiri-netbsd-desktop-20261105-fonts/emulator
python3 scripts/probe-xiri-xdm.py \
    --bundle .work/images/xiri-netbsd-desktop-20261105-type1 --winterm --fonts
```

The build uses zlib CHD compression and verifies an exact 8 GiB raw round trip.
The cold probe boots only the CHD's disk kernel, with an immutable graphical
NVRAM copy and the bundle's pinned emulator. It installs test helpers on a
private overlay; it does not reinstall the runtime or reset accounts.
Promotion requires both xdm users, three IRIX sessions, both logout routes,
recovery, native core/Xft pixel comparisons, untouched winterm geometry,
foreground resize, catalog launch, full-screen XAA and clean halt.
