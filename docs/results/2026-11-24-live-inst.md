## Installation

The clean images have an IRIX desktop import and no SGI installation
history. The installer installed selected files from eight base subsystems
using the original Foundation and matching overlay media. Its resolver
accepted the CD 4 game and Freeware index with zero conflicts. The two
runs used the same native kernel and module from NetBSD `df8a46a636f`.
SGI's timezone compiler created an alias that survived removal of the
original filename on both CPUs. The installer still prints warnings about
CPU identification and the volume-header device.

The installer chroot needs a character device at `/dev/zero` for SGI's
runtime loader. The bootstrap derives its major and minor from the native
device, and sets executable modes on the three mapped IRIX libraries
installed with mode 0444. During Freeware index generation the IRIX shell
and native utilities need to see the same `/tmp/mkindex.$$` files. A
temporary null mount supplies that scratch directory and is unmounted
afterward. The installed software and catalog page live at their final
paths throughout.

The original xmahjongg exit command calls `make -u` in `/usr/lib/filetype`.
SGI's full Makefile ignores several errors from unrelated rules and can
replace the live table even after reporting failures. The package
transaction stages a lowercase `makefile` beside it, which SGI make reads
first. It runs the original `fftr` inside the chroot from the installed
rule's directory. Both compilers produced the same 3,868-byte game table.
The native parent verifies its digest, merges it ahead of the saved
release-specific table with SGI fftr, then publishes the complete file by
rename. The temporary makefile disappears at the end of the transaction.
A pre-existing site makefile caused a clean refusal on both guests.

## Desktop and removal checks

SGI's own catalog helper created the **FreewareRelnotes** and **xmahjongg**
links. The original filetype library classified both the game and its
catalog link as `XMahjonggExecutable`, by filename and by open descriptor.
The xclock control retained its `XClock` type. A double-click in the original
Icon Catalog opened a 1006×614 board owned by uid 1234. Bringing the catalog
forward showed the open yellow tile. Clicking the game's Quit button closed
the board and returned the tile to its closed drawing.

After logout, the removal transaction cleared the game from `versions` and
removed its executable, catalog link, rule, and two icon drawings. The
separate Freeware release notes remained. Each active desktop table regained
its exact pre-install SHA256 and the named game rule disappeared. The tests
also compared the native and emulated account files, the Xorg configuration,
and the native null and zero device identities. Reinstallation restored the
same compiled table before the manual image was packaged. Both standalone
CHDs passed `chdman verify`. Each cold-booted to the 1280×1024 xdm greeter
and launched the game again through Icon Catalog as `xiritest`.
