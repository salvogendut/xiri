# Everyday desktop use on the clean v4 Indy images

The 6.5.22f R4400 and 6.5.30f R5000 runs used the v4 installer receipts,
accelerated Newport and a 1280×1024 Xorg display. Each test booted an
independent copy of the appropriate CHD and wrote to a private overlay.
The [release bundles and launch commands](2026-11-24-indy-v4-recovery.md)
can be used to repeat these checks.

| Action | IRIX 6.5.22f | IRIX 6.5.30f |
| --- | --- | --- |
| Double-click an original Icon Catalog entry | Applications → Acrobat opened the first-run Reader dialog. After accepting it, opening the bundled `Reader/Acrobat.pdf` from winterm rendered page 1. [PDF screenshot](2026-11-24-indy-v4-use-6.5.22f-catalog.png) | ControlPanels → colorscheme opened the 326×367 Color Scheme Browser. The separate nedit attempt showed icon activity without a mapped editor. [Browser screenshot](2026-11-24-indy-v4-use-6.5.30f-catalog.png) |
| Create and move a file in File Manager | Both releases created a copy with Ctrl+C, then moved it between two File Manager windows with a middle-button drag. | Both destinations contained the original 13 bytes, owned by `xiritest`. The copy was absent from the source directory after the drag. |
| Save and cold-boot | The original Background Setting panel applied Solid. After logout, clean halt, cold boot and xdm login, 4Dwm restored two winterms and `sgiLightBlue`. [Restored desktop](2026-11-24-indy-v4-use-6.5.22f-restored.png) | The same check restored both shells, the chosen background and the moved file. [Restored desktop](2026-11-24-indy-v4-use-6.5.30f-restored.png) |
| Log in as another IRIX user | `xiritest2` opened a first session with one terminal, its own home and the default granite backdrop. | Same result. Each terminal handed off to the logged-in user's UID. |
| Log in as a native NetBSD user | `netbsdtest` opened ctwm and UXTerm at full resolution. | Same result. |

To repeat the session check, add a second terminal with `xiri-launch winterm &`,
run the vendor `/emul/irix/usr/bin/X11/tellwm save_configuration`, then log
out before shutting down. Compare the actual terminal count and
`_SGI_DESKS_BACKGROUND_DESCRIPTION` after the next xdm login. 4Dwm writes
the application list under the user's `~/.desktop-127.0.0.1/0.0/4Dwmsession`.
A native administrator can create a second opted-in account using the
[desktop-user instructions](../NATIVE-PACKAGE.md#select-the-desktop-after-installation).

An earlier 6.5.30f harness interruption ended one exploratory run without a
clean guest halt. The recorded save and cold-boot results use the subsequent
clean shutdown and restart. The [per-release measurements](2026-11-24-indy-v4-use.json)
include image hashes, window identities, terminal UIDs, file digests and
shutdown outcomes.
